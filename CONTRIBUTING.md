# Contributing

Contributions to this repository should improve public documentation.

## Welcome contributions

- Clearer explanations of the mission and product areas.
- Corrections to wording and broken links.
- Accessibility and readability improvements.
- General feedback that does not contain private data.

## How to contribute

1. Open an issue describing the documentation change.
2. Keep proposed edits focused and factual.
3. Submit a pull request with a short explanation of the change.

Do not submit proprietary application code, credentials, configuration files, database exports, customer records, or copies of material from private repositories. Describe uncertain product behavior as uncertain rather than presenting it as a verified capability.

Security concerns should follow SECURITY.md rather than being disclosed in public issues.
