# Security and privacy

## Public repository boundary

This repository contains public-facing documentation only. It has no application runtime, authentication system, broker integration, or deployment configuration.

Do not publish:

- Passwords, API keys, tokens, session cookies, or recovery codes.
- Environment files or production configuration.
- Proprietary source code or private repository history.
- User records, account identifiers, trade records, or unredacted screenshots.

## Reporting concerns

Do not disclose suspected vulnerabilities or sensitive information in public issues or pull requests.

If GitHub's private vulnerability reporting feature is available for this repository, use it. Otherwise, use a verified private contact channel provided by the project owner or through the TradeGuardian website. This document does not invent or designate an unverified security email address.

## Product claims

Public documentation must not claim broker-side enforcement or complete monitoring coverage without evidence for the relevant deployed integration. Missing telemetry is not evidence of compliant trading.
