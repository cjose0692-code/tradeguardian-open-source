# TradeGuardian

**Discipline. Control. Consistency.**

TradeGuardian is a trading discipline project focused on helping traders define their own rules, recognize rule-breaking behavior, and review their decisions with greater accountability.

## Mission

A trading plan only helps when it guides actual decisions. TradeGuardian's mission is to make personal trading rules clear, actionable, and easier to follow before, during, and after a trading session.

## Product focus

- **Personal rulebooks:** Define position-size limits, trading windows, daily trade limits, and risk boundaries.
- **Guardian and Risk Guardian:** Support rule awareness and risk-control workflows.
- **Decision checkpoints:** Encourage a deliberate pause and a clear reason before acting.
- **Journaling and review:** Record trades, decisions, and lessons for structured reflection.
- **Analytics and coaching:** Help traders examine patterns in their execution and discipline.
- **Violations and progress:** Make rule adherence visible over time.

These describe the product's focus. Availability and enforcement depend on the deployed version, supported platform, permissions, and available data. This repository does not verify broker-side execution or promise universal order blocking.

## Repository scope

This is a public documentation repository. It contains documentation written specifically for public sharing; it does not contain the proprietary TradeGuardian application or extension source code, deployment configuration, credentials, or customer data.

The repository name `tradeguardian-open-source` does not mean the proprietary application has been released as open-source software. No application source code or application license is provided here.

## Feedback

Use GitHub Issues for documentation suggestions and general product feedback. Do not include account identifiers, trade records, screenshots containing personal information, credentials, or security vulnerabilities in public issues.

TradeGuardian is a discipline tool. It does not guarantee trading results or replace a trader's responsibility for risk decisions.
